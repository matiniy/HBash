# Social logos

Place your 3 logo image files in **this folder** with these **exact** names so they appear above the footer:

- **logo1.png** (or logo1.jpg / logo1.svg — then update `SocialLogos.tsx` to use the same extension)
- **logo2.png**
- **logo3.png**

If the files are missing, the logo section will not be shown. Once the files are here, they will render automatically.
